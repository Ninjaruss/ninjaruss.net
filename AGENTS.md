# ninjaruss.net

Personal Astro 5 site.

## Commands
npm run dev
npm run build
npm test

## Rules
- Preserve the existing P4G-inspired visual system.
- Prefer existing components/design tokens over adding new systems.
- Do not modify content unless the task specifically requests it.
- Run tests and build after implementation.
- Read relevant docs under /docs before changing a subsystem.

## Architecture
- src/components — reusable UI
- src/content — content collections
- src/pages — routes
- src/utils — application utilities
- docs — detailed project documentation
