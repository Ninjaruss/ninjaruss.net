# Character direction lock — focus pass

Dated 2026-09-17. A focus pass over the character sheets, asking one question:
*which details define the character's direction, and which are decoration or
mechanics in the wrong place?* Proposal only — the author rules.

## State first

The seven main sheets share one framework — **Quick Read → On the Page →
Want/Fear/Change → With Others → mechanics → Visual Anchors → Do Not Flatten** —
and every sheet already carries the four things that actually define a person.
So the "flooding frameworks" problem is solved; the open question is now
**altitude**, not structure.

The four load-bearing things (keep these tight):

1. **Contradiction** — one line of internal tension.
2. **Question** — the single decision the arc tests.
3. **Arc beats** — the numbered list (this *is* the outline direction).
4. **Defining mechanic + its psychological cost** — one line, tied to the
   psychology, *not* the full combat spec.

## Where the overcomplication actually sits

Not evenly spread — concentrated in the **mechanics sections**, at three altitudes:

1. **Decorative precision** — exact heights. Six sheets carry a height in inches
   (`0 Rain.md:9` 5'7", `1 Vesper.md:9` 5'6", `Claire.md:9` 5'10", `Roxana.md:9`
   5'5", `Shiori.md:9` 5'8", `The Pursuer.md:9` 6'2"). Only two carry function:
   Vesper's slightness (threat comes from certainty, not size) and the Pursuer's
   largest silhouette. The rest define nothing a scene would contradict.

2. **Compressible** — the trait word-pairs (`0 Rain.md:13` "Soft Yearning / Sudden
   Resolve", etc.). They're a legitimate compression, but they overlap the
   Contradiction and the "On the Page" tells, so they're the lowest-cost cut if
   anything has to go.

3. **Wrong altitude** — combat/system micro-spec. Several sheets specify the *power
   system*, not the *person*: the Pursuer's four named vapor effects
   (`The Pursuer.md:79–85`), and symptom ladders on Rain (`0 Rain.md:99`),
   Claire (`Claire.md:85`), and Roxana (`Roxana.md:87`). These are mechanical, not
   direction. This is the exact inverse of the register's "cluster 1" finding
   (`findings.md:173–186`): the world-rules layer is *under*-specified in
   `World/Magic System.md` while being *over*-specified here.

   The symptom ladders are at least **consistent** — same "escalate → collapse"
   shape on all three — which is good, but they belong in the mechanics owner,
   not the character direction.

## Proposal (not applied)

- Keep each sheet's **Contradiction / Question / beats / Do-Not-Flatten** as the
  direction lock.
- **Relocate** the combat micro-effects and symptom ladders into
  `World/Magic System.md` — that document needs exactly this detail for its
  tightening pass, so nothing is lost.
- **Demote** exact heights and the trait word-pairs to optional texture, keeping
  only the two that function (Vesper's slightness, the Pursuer's silhouette).
- **Delete nothing yet.** This is a relocation + altitude proposal; the author
  rules, and the register records the ruling.
